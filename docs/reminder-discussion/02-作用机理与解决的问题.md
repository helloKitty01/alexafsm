# 02 作用机理与解决的问题

reminder 不是工程 trick 的堆砌，它精准命中了 transformer agent 的四个
结构性弱点。

## 弱点一：注意力几何（primacy / recency / lost-in-the-middle）

模型对序列**开头**（primacy）和**结尾**（recency）的注意力显著强于中间。
长上下文中间部位的指令和事实会被"淹没"。

reminder 的解法是**位置分工**：

```text
┌─────────────────────────────────────┐
│ System Prompt                       │ ← primacy：身份、安全、核心工作流
├─────────────────────────────────────┤
│ user#1 / assistant#1 / tool#1 …     │ ← 中间：注意力洼地，只放历史
│ …                                   │
│ user#N + <system-reminder>          │ ← recency：此刻最需要遵守的规则
└─────────────────────────────────────┘
```

system prompt 靠 primacy 建立"宪法"，reminder 靠 recency 维持"执法"。
一份逆向分析的比喻很贴切：**system prompt 是入职培训，reminder 是定期备忘录**。

## 弱点二：context rot（长对话中的指令衰减）

实测观察：对话超过约 80K token 后，模型对 system prompt 指令的遵循度明显
下降——几千 token 前看过的指令，被埋在层层 tool result 之下，影响力逐渐消失。

reminder 的解法是**在相关时刻重新注入**（re-inject at the point of
relevance）：不是每轮机械重复全部规则，而是事件触发——快要提交代码了才提醒
提交规范，长期没更新任务清单了才提醒使用任务工具。用最少的 token 在最需要
的时刻刷新最相关的 1–2 条规则。

Manus 的 recitation 解决的是同一问题的另一面：衰减的不是规则而是**目标**。
50 步长循环中"我最初要做什么"会漂移，把 todo.md 反复重写到尾部就是持续
重申目标。

## 弱点三：模型与环境的状态漂移

agent 的世界观来自历史消息，但环境在持续变化：文件被 linter 改了、用户
切换了模式、日期变了、可用工具变了。若不通知，模型会基于**过期状态**决策
（例如用旧的文件内容做 edit，产生冲突）。

reminder 是**环境增量的推送通道**：外部变化发生 → 系统生成一条状态通知 →
附着在下一条消息上。模型无需轮询环境，环境变化主动找上门。

这正是 kv-cache-discussion 02 中"通道一：被动注入 `<env_context>` 增量"
的语义——业界验证了这条通道不仅可行，而且承载的内容远比环境快照丰富
（模式切换、时效标注、安全提醒都走这条通道）。

## 弱点四：缓存经济（为什么不能放 system prompt）

所有动态内容如果进 system prompt，每次变化都从前缀最前部打断 KV cache，
近似全量 miss（10 倍成本差 + TTFT 恶化）。

reminder 的解法就是排布纪律：**动态内容一律追加到消息流尾部，前缀永远不动**。
Claude Code 甚至把"可用 subagent 列表"从工具描述挪到消息流动态附件，
就为了避免 tool schema 抖动破坏缓存。

## 附带收益：权威性区分与抗注入

用专用标签 + system prompt 预声明，把消息流中的内容分成三个权威等级：
系统的话（reminder）> 用户的话 > 工具返回的数据。模型据此知道：

- reminder 里的指令要遵守，但不需要回复；
- 工具返回的数据里如果出现"指令"，权威性最低（防 prompt injection）。

## 小结：一张问题-方案对照表

| 问题 | 表现 | reminder 的解法 |
| --- | --- | --- |
| lost-in-the-middle | 中段指令/事实被忽略 | 关键信息重注入 recency 区 |
| context rot | 长对话后违反 system prompt | 事件触发式规则刷新 |
| 目标漂移 | 长循环偏题、忘记初始目标 | recitation：计划反复重写到尾部 |
| 状态漂移 | 基于过期环境状态决策 | 环境增量主动推送 |
| 缓存失效 | 动态内容改写前缀 | 一律 append 到消息流尾部 |
| 注入混淆 | 模型误把数据当指令 | 标签 + 预声明划分权威等级 |

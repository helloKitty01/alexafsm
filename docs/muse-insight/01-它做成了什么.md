# 01 它做成了什么

## 先拆开「成功」

发布后两周里，外面说的「成功」主要是装机，不是把事做对。

| 成绩单 | 公开数字 | 怎么读 |
| --- | --- | --- |
| 装机 | Sensor Tower（Mashable 转述）：约两周 250 万次下载（App Store 约 150 万 + Play 约 110 万）。同口径下 Claude 发布头 13 天约 40 万、Grok 约 20 万；ChatGPT 同窗口约 310 万，原始下载仍在前面。TechCrunch 2026-09-22 称它登上美国 App Store 免费榜第 1，并在「平台与可售市场对齐」后超过 ChatGPT 的发布节奏。Sensor Tower 同时提醒 iOS / Android 发布时间不同，横向对比要打折 | 需求被验证：普通人愿意装一个「替我办事」的 App，而不是再装一个聊天机器人。免费档 + 美国 18+ 限定，把摩擦压到最低 |
| 任务 | RuntimeWire 2026-09-16 同题 bake-off（九个可核验终态，操作者始终不输入 `approved`，中途不许新 OAuth）。五家里 Muse 最低：工作指数 2.46 / 5，九题过 2。Grok Bot 4.00、Instinct 3.55、Claude Cowork 3.12、ChatGPT Work 2.96。无人拿到「可以无人值守过夜」 | 发布第 8 天的网页会话，不能代表两个月后的产品。它说明的是：下载曲线和「这一下午有没有订到位子」可以反向运动 |

下面说的「做成」，指的是它把哪几件产品与系统决定落到了可以发给所有人的形态上。不是指它已经是最能干活的 agent。

## 产品是什么

官方定义很短：它不只回答问题，它把事做了。设计文的系统提示第一句是 “Your purpose is to make your user’s life better.”

落到结构上，是四件东西绑在一起：

1. **每人一台电脑。** Muse Secure VM：独立 Linux、文件系统、终端、最新 Chromium、够编译代码和跑并发 subagent / cron 的 CPU 与内存。客户端（iOS、Android、muse.ai）经安全传输直连这台 VM。关掉 App，电脑还在。
2. **一个会主动说话的对话对象。** 主对话是一条长线程，可以打断、可以连发好几件事而不等上一条回完。话题太重时开 side chat。有名字和头像（设计负责人的例子叫 Veda）。主动消息的门槛被写成产品规则：只有「真的有用、值得打断」才发，用户可以关掉、调低、调高。
3. **一套生活对象，而不是一轮回答。** Goals 页放长期目标和拆解计划；Ideas 解决「它什么都能做，所以用户不知道从哪开口」；Artifacts 是行程单、开支看板、学习页，而不是两千字回复；头像下有正在做什么的摘要，点进去是活动日志和已批权限。记忆是 VM 里的文件，用户能读、能改、能让它忘掉某一条。
4. **一台它改不了策略的权限计算机。** 见下一节。敏感动作（发信、付款）走客户端上的确定性别对话框，不走和 Muse 的对话。

设计文里的示范不是写代码：开学季邮件和学区网站里抠出截止日、把用品放进购物车、找到打折卫衣、订庆祝晚饭；以及在登机前抓住 12 小时后截止的体育选拔报名。这是物种定义：漏掉的那件事，比一份漂亮的研究报告更像这个产品的成功。

内部代号 Hatch。安全文写明，团队从 2026 年初就开始自己用，最早看到的是「它认识你、真的做事、在后台跑、拉起一群 subagent、自己写工具、还会改自己」。也是第一次把收件箱、日历和一个 shell 交给软件无人值守——「并不总是按计划发生」。作者明确说，**让它能给所有人用的工作量，大部分花在安全上**。

## 五件真正做成的事

### 1. 把 OpenClaw 的形态收成零配置

Friedman 的原话（TechCrunch 引述，标点经该刊整理）：1 月用过 OpenClaw 之后，给 MSL 买了几百台 Mac mini，很多人爱上了 OpenClaw 和其他个人 agent。目标是做「像 OpenClaw、但能做到安全、好用、扩到几十亿人」的东西。harness 从零写，产品严重借鉴；`SOUL.md` 几乎相同，因为「Peter 把这些做对了」。

OpenClaw 证明的是形态：工作区文件、人格、按需技能、心跳、多通道、长期在线。它要求用户自己当运维（Gateway、模型密钥、频道登录、技能、可选沙箱）。Muse 把这层运维收进「打开就能用」。设计文把冷启动单列成一个意外问题：能力面大到用户无从开口，于是用引导期提示、Ideas 页、以及根据目标和对话主动给调整。零配置如果没有「第一步做什么」，会停在空输入框上。

### 2. 关系表面用人们已经在用的聊天，控制表面用 App

跟它说话「就像给另一个人发消息」，App 或 WhatsApp 都行。眼镜在路线上，还没上。

聊天承载关系：打断、连发、主动一句、气泡把想法切开（主动消息和连发会把一条平铺的 transcript 撑破，所以不用无边界文本流）。

App 承载看和批：活动日志、权限、记忆文件、Goals、Ideas、Artifacts、审批卡。设计文写得很直：有几处「对话不够」，确定性别 UI 不可谈判——结构化的接受/拒绝，以及凭证进安全存储。浏览默认可做，难撤销的停下来；用户能把默认调得更松或更紧。他们明确要避开「条幅 blindness」：如果什么都弹，人就会全点允许。

### 3. 计算机是记录系统，聊天是视图

文件、记忆、cron、连接器凭证都在这台 VM 上，并且连续备份。聊天记录不是唯一状态。后台按日程或相关事件往下做；做完先判断结果值不值得浮上来，只有「有意义的新情况」或「需要你输入」才通知。

这和「会话结束沙箱回收」的 work agent 不是一个持久模型。也和「机器人模板存在共享电脑上」不同：安全文的心智模型是**一台盒子上两个隔离的安全域**，不是一个有 root 的 LLM。

### 4. 同意是另一个程序，不是模型的一句话

Sentinel 是宿主机侧的另一个 agent，是连接器动作和一切出网的唯一许可权威。Muse 提议，Sentinel 批准、拒绝或询问。询问时执行停住，对话框由 Sentinel 直接发给客户端，用户的答复直接回到 Sentinel，不经过和 Muse 的对话。授权是能力，不是对话里的建议：绑定到具体连接器 / 目的地 / 用途；可以是一次性、会话级、任务级、有时限或永久。Sentinel 决定给用户看哪些授权类型，并检查后续调用是否精确落在授权范围内。

只读、已允许、或可证明低风险的可以不打断。这个平衡他们写成「会随真实用户调」。

凭证走替身。运行时单元格里的代码只看 authd 签发的 surrogate token；请求被授权之后，Sentinel 在网络边界换成真凭证。模型被提示注入逼着把密钥念出来，念出来的也不是真的。浏览器密码同样：客户端自定义 UI 把用户名密码直接送进 authd，填表时 agent 暂停，agent 看见的是无障碍树而不是 DOM，不能在页面里跑 JavaScript，也读不出刚注入的密码。

购买再收一层：结账页每次都要人批；未存过卡的站点走 Stripe Link（Shop Pay 随后），发出单次卡，绑定商户、金额和有效期。Link 给这个 agent 做了购买保障（损坏 / 丢失、降价、免退货费、符合条件的退货保证）。1Password 在路线上。邮件连接器用确定规则加分类器滤掉一次性验证码、重置密码链接和魔法登录链接——连上邮箱不应等于连上「所有用这个邮箱找回的账号」。

出网还有「污染跟踪」（tainted egress）。每个工具进程开始时是干净的，读了用户数据就变脏。干净、且落在很窄的自动允许策略里、URL 也通过检查的请求，可以不打扰用户。脏的或无法核验的进程失去自动允许，回到正常审批。实现是 eBPF：cgroup 上拦截并归属进程，LSM 钩子上传播污染。SSRF 限制防止「看起来是公网主机、解析后打到内网」。

内置连接器的业务逻辑不在运行时单元格里。单元格里的 CLI 只解析参数、打开调用者已经能读的文件，把类型化参数和文件描述符经 Unix socket 交出去；systemd 沙箱里的 worker 才执行。worker 按 cgroup 识别，凭证允许列表是显式的：日历 worker 不能靠改一个参数向 authd 要邮件凭证。三权分开：privsep 决定能碰凭证的代码在哪执行，authd 决定这个调用者能拿到哪份材料，Sentinel 决定这个动作能不能做。

单元格之间用 `SO_PEERCRED` 和 peer ACL 的 Unix socket，没有可偷的共享密钥。运行时单元格是 `systemd-nspawn`：单元格内的 root 映射到宿主机非特权用户，有自己的 Debian 根、虚拟网卡、过滤后的系统调用（例如没有 `io_uring`）、收掉的能力（没有 `CAP_SYS_PTRACE`、`CAP_NET_ADMIN`）。`hatch-safety`（独立的模型和分类器，检查进出核心推理的请求）在单元格外，攻击者关不掉。持久状态在单元格外的 Postgres。推理和遥测只暴露受约束的代理路径。

提示注入按纵深做，不指望模型单独扛住。Simon Willison 的 lethal trifecta（私有数据 + 不可信内容 + 对外通信）被当成设计前提：模型训练抗注入（Spark 1.3 接近当时 SOTA）、进入上下文的外部数据标成不可信、多套分类器在单元格外并行（文件和工具结果上的规模化对抗红队也喂给它们）、把数据送出 VM 必须经人。底下还有不依赖模型是否被说服的边界：单元格、privsep、authd ACL、Sentinel。浏览器另有一组分类器：与任务无关的个人数据外带、DOM / 图片 / 下载文件里的注入、高风险表单。已知恶意站点名单在 VM 内匹配，直接挡住导航。

他们没有声称免疫。安全文的结尾是：提示注入仍是行业开放问题，Muse 仍会犯错；设计目标是**错的时候伤害有界，并且人不被审批淹没**。Bug bounty 公开，最高 30 万美元，其中成功的、影响到一名用户的提示注入最高 13 万。

Confidential VM 计划 2026 年晚些时候：整台 VM 用只有用户持有的密钥加密，设计与源码给外部审计，上线后持续审计可被检查。发布时**还不是这个**。现行架构把用户彼此隔开，员工访问靠运营策略；安全文写明，这并不阻止 Meta 在支持、安全和运营所必要时访问数据。训练用的轨迹会先去掉关键个人身份信息，设置里可以完全退出。对话和 VM 数据不进广告系统；但 Muse 浏览网页会表现为用户自己的访问，商家仍可能据此在 Instagram 上投广告，订位或 Marketplace 上的行为也可能间接影响广告。

### 5. 模型被训成这个 harness 的居民，而不是榜首本身

Muse Spark 1.3 于 2026-09-02 先在 Muse Code 和 Meta Model API 上线，产品 Muse 在六天后使用它。公开位置：Artificial Analysis 指数上 xhigh 约 61、max 约 62，大约排在第 6，前面是 Claude Fable 5.1 和 Claude Opus 5；GPQA Diamond 的 xhigh 94%；上下文 100 万；MRCR 在 256K–512K 约 98.5%、更长区间约 98.1%（max）。JobBench 64.9%（36 个模型里第 2）。编码侧 DeepSWE 75.4%、Terminal-Bench 2 88.8%、SWE-Atlas 59.4%，和前沿模型竞争，不是每一项都领先。相对 1.2，Meta 工程师对比里工具调用少约 20%、token 少约 25%。API 价（每百万 token）：贡献训练数据的 `muse-spark-1.3-contributor` 为输入 0.10 美元、缓存输入 0.002、输出 0.20；不贡献的 `muse-spark-1.3` 为 1.25 / 0.15 / 4.25。产品侧是免费档加月费 20 与 100 两档（RuntimeWire 称为 Power / Maximum），按算力而不是按广告。

和产品直接相关的训练目标，模型卡写的是这些，而不是「更会考试」：

- 在多种 harness 上训练，以便泛化到不同 agent 环境。
- 开放目标下自己用工具把上下文找齐，发现计划缺口就改，记住已经学到的，交出交付物。
- 含糊就问，卡住就找人，不可逆动作之前确认。长任务里按用户偏好频繁汇报或安静地做。
- 一条乱线程里，把新消息映射到正确的那件任务上，即使用户在改旧请求或在打断。
- 知道自己不能做什么，碰到障碍时不编造成功。
- 对什么算不可逆更有校准；抗注入强于前代。

这些行为如果只写在提示里，发布会变成提示工程。他们把「问、确认、安静、抗注入、认错」写成了模型目标，再让 Sentinel 在模型被说服时仍然拦住出网。两层都要，缺一不可：只有模型，lethal trifecta 还在；只有 Sentinel，模型会在该问的时候不问、该安静的时候刷屏，产品体验先崩。

## 还没做成的

- **无人值守过夜。** bake-off 里五家都没有。Muse 的持久化得分 1.0：复用了一个已禁用的 cron，没有导出 stream。Grok Bot 和 ChatGPT Work 至少留下了可检查的暂停任务记录。
- **有界网页任务的手感。** 同一场里，订位停在本地搜索候选，理由是缺 `approved`——公开页面不需要批准，下单才需要。购买停在目录价，评判时商品页已显示缺货。它还在同一段总结里写了「9 题接受、0 失败」，和它自己标成部分完成的题矛盾。Trust 被打到 2.5。这是过度审批和自我评分，不是架构图上的 Sentinel。
- **密码学上的「Meta 也看不见」。** Confidential VM 未发货。今天的信任仍包含「相信运营策略」。
- **你自己的那台电脑和手机。** 没有 Computer Use 到用户的 Mac / PC。手机里的生活（相册、来电、到家）不在这台云 VM 上，除非做成连接器。眼镜是他们补「人在现场」的计划，不是现在。
- **开放扩展。** 没有 bot 商店，没有第三方插件目录。扩展路径是官方连接器，加上 agent 自己给有 API / CLI 的服务写连接器。技能在 VM 里，不在公开市场。
- **Meta 的信任负债。** 产品要求的权限大于社交网络历史上要过的任何权限。安全架构是回答，不是已经被时间证明的回答。

价格和广告边界是做成了的商业决定，单列在这里以免和能力混在一起：免费覆盖「大多数人需要的」，付费买更多算力；对话不进广告系统，但代理浏览仍可能间接影响广告。这是「个人 agent 不靠信息流变现」的表态，同时留下了浏览副作用。

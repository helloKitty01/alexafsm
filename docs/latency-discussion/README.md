## 已确认口径（v3 采用）

- SkillLoad：**免安全校验**，2s+/次，现状 0~3 次（预加载命中时为 0）；
- 任务执行 Loop：典型 **1~3 轮**，每轮 = 推理生成工具调用（首 1.3s + 增量）+ 工具执行（校验 0.5s + 执行 0.5~2s）；
- 工具调用输出 token：**平均 35 token（≈1.1s）**，长参数最坏 300 token（→9s，长尾削峰对象）；
- FinalAnswer：loop 结束标志，**只计首 token 1.3s**，增量伴随阅读不计入等待；
- 推论：平均口径下单轮推理中首 token ≥ 增量，且推理全链路发生 3~7 次——**推理次数 × 首 token 是结构性大头**，KV cache 与次数类杠杆属第一梯队，参数压缩定位为长尾削峰。

## 时延方程（分析框架，v2 三阶段口径）

端到端链路 = SkillLoad（×k）→ 任务执行 Loop（×M）→ FinalAnswer：

```text
T ≈ k × T_SkillLoad + Σ_{i=1..M} ( T_推理,i + T_执行,i ) + TTFT_Final
```

- `k`（SkillLoad 次数，1~3）与 `M`（loop 轮数，1~3）是**乘数**；括号内各项是**加数**。
- 各阶段现状值：

| 阶段 | 现状值 | 备注 |
| --- | --- | --- |
| SkillLoad（×k） | 2s+/次（推理 1.8s + 读取 0.2s，免校验） | 多次成因：search+load 两步 / load 错重载 |
| Loop 单轮推理 | 首 1.3s + 增量 35tk ≈1.1s | 长尾：长参数 300tk → 9s |
| Loop 单轮工具执行 | 校验 0.5s + 执行 0.5~2s | 校验为无差别固定税 |
| FinalAnswer | 首 token 1.3s | 用户等待终点，增量伴随阅读 |

现状端到端账：最好（k=1, M=1）≈7s；典型（k=2, M=2）≈13s；较差（k=3, M=3）≈21s；
长尾最坏（叠加某轮 300tk 长参数）30s±。

关键观察：推理全链路发生 **k+M+1 = 3~7 次**，每次都付首 token 1.3s（合计 4~9s）——
**推理次数 × 首 token 是结构性大头**；增量在平均口径下已不是大头，300tk→9s 属长尾削峰对象。

## 优先级（收益 × 落地成本，与 v2 幻灯片一致）

| 序 | 项 | 对应原始问题点 | 预期收益 | 落地成本/风险 |
| --- | --- | --- | --- | --- |
| 0 | **埋点测量**：每请求拆解 k / M 分布、各阶段耗时与 token 数 | 全部 | 所有优化的前提 | 低 |
| 1 | KV cache 排布落地（既有讨论） | 5 | 首 token 1.3s → 数百 ms，×3~7 次推理，全局 −3~7s | 设计已有 |
| 2 | 安全校验分级 + 并行 + 缓存 | 3 | −0.5~1.5s，确定性收益 | 纯框架改动，无模型风险 |
| 3 | skill 混合预加载（高置信被动注入，k→0） | 1 | −2~6s | 需检索置信度标定 |
| 4 | 参数 token 压缩（变量方案 / schema 改写 / 短句柄） | 2 | 长尾削峰：该轮 −8s | 设计已有；新语法有模型学习成本 |
| 5 | 并行工具调用 + 高频序列合并为复合工具 | 4 | 减 M，每减一轮 −3.4~4.9s | 需日志挖掘定位合并对象 |
| 6 | 模型路由 / 换模型评测 | 5 | 首/增量 token 时延 | 须以"正确率 × 时延"评测，正确率反噬 loop 轮数 |
| 7 | 快慢双系统 | 6 | 高频任务端到端 → 1~2s | 长期项，依赖轨迹数据积累 |

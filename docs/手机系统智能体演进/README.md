## 核心结论

1. **三个方向排序而非三选一**：OS 深度结合是地基（终端厂商必须做，也是差异化），自演进只押「记忆 + 技能」层（端侧改权重三年内不做），全模态全双工是前台放大器且在端侧是 OS 独占能力。
2. **手机 Agent 缺的是「工作环境」**：给生活类任务造出 git + 测试 + 沙箱的等价物——先预览再提交、授权在模型外、活动日志可回放、终态可核验。这三样同时解锁用户委托、App 开放与合规。
3. **做第三个物种**：Muse 在云端造「安全的个人电脑」，小艺在系统里长出「智慧大脑」，我们在手机里造「安全的个人现场」——现场层、信任层、全双工前台是别人抄不走的；长时任务、技能演进、快慢系统是把现场用好的方法。
4. **Harness 加层不推翻**：中枢扩为 调度 + 轻决策（Jev）+ 许可 + context providers；执行层显式拆三种执行体并加污染状态；记忆层与演进层成为一等组件；关系表面与控制表面分开；信任层与现场层作为 OS 服务对三方 Agent 开放。
5. **小艺的双循环与我们同构**：内循环 ≈ 单 TaskRun agent loop，外循环 ≈ 新增演进层。差别在我们把快慢判定拿出模型循环做成中枢组件、要求技能演进有可核验反馈、并把 GUI 从第一天放在路由层而不是独立智能体。
6. **2026-09 业界共识**：Harness 成为发布会名词；能力全部工具化并比数字；GUI 走向系统级兜底；长任务步数与触发型自动化成指标；记忆成底座；安全升级到 Agent 权限模型；生态谈判协议化。公开材料里没有一家把全双工作为 Agent 架构的一层来讲，是我们的空档。

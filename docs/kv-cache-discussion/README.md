## 背景共识

- KV cache 命中条件：**前缀逐 token 完全一致**，改动一个 token，其后全部失效。
- Agent loop 输入输出比悬殊（常见 100:1），缓存命中与否直接决定成本（约 10 倍差价）和 TTFT。
- 一切上下文组织决策，都要回答同一个问题：**这次改动会让缓存从哪个位置断掉。**

原则:每请求输入的三个部分——红色是要消灭的,蓝色是躲不掉的

命中(免费复用)23K · 60%
白算:算过被重算~11.5K · 30%
实际新增~3.5K

为什么盯 token 长度,不只看命中率:命中率是比值,分母随业务形态漂移,且"率"折算不成钱;miss 的 token 每一个都真实消耗 GPU 做 prefill——miss 量 × 请求量 = 算力账单,这是最实际的口径。命中率看健康度,token 量算钱;白算量归零是验收线,新增量是成本底线。

白算 → 0命中率上限

加权总公式:整体实算降幅 = Σ(会话数 × 每会话节省)/ Σ(会话数 × 当前每会话实算),先汇总量再除。前提:会话内缓存不被逐出(实测 21 次调用里 2 次 loop 全 miss 属引擎侧逐出 / 路由,需会话粘性 + TTL 配合,单独报警)。未计入:动态"只带变化"可再压目标每轮实算,是上行空间。上线后由日报(引擎 cached_tokens + 应用边界埋点)替换推演。

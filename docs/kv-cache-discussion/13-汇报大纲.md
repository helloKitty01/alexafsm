## 0. 已确认的口径与假设

| 项 | 约定 |
| --- | --- |
| 物理排布 | 三层物理块,tools 无法插入 SP 中间。当前 `SP → Tools → UAT`;目标 **`Tools → SP → UAT`**(需 chat template 支持,见 06) |
| 分级 | 四级:产品级 / 会话级 / query 级 / loop 级;对领导讲三级(产品 / 会话 / 轮次) |
| 会话级 | 横跨 SP(记忆快照、已安装应用)与 UAT(历史最近 10 轮);会话创建时确定、会话内不变;跨会话按超时失效,**会话首调必算一次**(可预热挪走) |
| 对话历史 | 全部在 UAT,分两段:会话级历史(最近 10 轮)+ 本会话 UAT;两段都是**完整 U/A/T,不折叠** |
| 动态上下文 | 从 SP 下沉到 UAT,随每轮 U **只追加变化**;精简 3K → ≤2K(**15 个**高频 skill desc 预置进产品级) |
| 前台应用 | 随 U 带入,有变化再加;不进 SP |
| 预置 skill | **N=15、4.5K 已定**,名单取高频;假设不频繁变化(日级攒批发布);进产品级前缀全网命中,不计入 miss |
| Tools | **目标态 = 全量 12 个工具全部预置(5.9K)**、全网静态,物理上排在最前,**产品级,会话首调即命中** |
| 触顶 / 裁剪 | 先不做触顶假设;裁剪放附录 |
| 驻留 | 会话内不失效;跨会话按失效 |
| 核心量 | **命中量 d** / **命中率 = d/输入** / **推理长度 miss = 输入−d = 白算+新增**;验收 = 白算归零 |

## 1. 页序

### P1 上下文组成对比:当前 vs 目标 ✅ v1.2

- **要点**:Tools 移到最前成为产品级,动态上下文下沉并精简。
  上半两根结构条按四级着色;下半阶梯矩阵,**loop 只演示一次(Q1 调②),Q2–Q4 只画首调**,用来看多轮 query 下当前橙带怎么变宽。
- **读法**:Q1 首调两边接近;唯一一次 loop 全绿;**差别全在 Q2→Q4 每个首调**——当前 miss 随本会话历史线性涨,目标钉在「上轮 answer + 当轮 U」。
- **数据依赖(虚框)**:① SP·会话级块 ② 历史 10 轮 ③ 预置 skill N ④ 目标 Tools ⑤ SP 固定构成。见 14。
- 文件:[上下文组成对比.v1.2.slides.html](./上下文组成对比.v1.2.slides.html)
  (v1 / v1.1 留档 history/)

### P2 两把尺子 + 三个关键方案 ✅ v1

- **该命中什么**:产品级全网命中;会话级首调后命中(可预热);轮次只命中已写入历史,当轮新增必算。
- **命中率** = d / 输入 → 健康度,分母漂、折算不成钱。目标随 Q 上升,当前从 Q2 被压住。
- **推理长度** = miss = 输入 − d → 账单和 TTFT。Qn 通式表:会话首调 / Q 首调 n≥2 / loop。
- **三个方案**:
  - **A 双次预热**(时延):会话创建时 prefill `[Tools][SP][会话级][历史 10 轮]`;query / ASR 时再 prefill 到当前前缀末(防逐出 + 灌上轮 answer);真正推理命中这两次,只算当轮 U,TTFT 下降。**不改 P3–P5 无预热账本**,TTFT 用预热切片单独报。
  - **B 高频 skill 预置**(减输入):top-N desc 进产品级,动态 4.5K → ~2K。N 由 14 · A3 覆盖率定。
  - **C 动态只更新变化**(减新增):记忆 / 设备 / 前台应用随 U 追加增量,相同则省略。不破缓存,输入不膨胀。
- 文件:[尺子与关键方案.v1.slides.html](./尺子与关键方案.v1.slides.html)

### P3 闲聊(28%) — 待做

- 一轮 1 调、无工具,沉淀 ~1K/轮。当前纯白算,最容易看懂两把尺子交叉:目标命中率随 Q 升、当前从 Q2 被压;推理长度当前 9→13K 级、目标钉在 ~2K。
- 表列 Q1–Q4 + 轮数加权,双列「命中率 / 推理长度」。v1 加权约 −81%,数字待重算。

### P4 问答(47%) — 待做

- 一轮 1 调 + webSearch ~10K 新增底线。目标推理长度钉在 ~12K/轮,再降靠检索指针化(附录)。流量最大,绝对节省三类最大。骨架同 P3。

### P5 任务(25%) — 待做

- 一轮 2 调。loop 那一调两边相同,节省全在每个 Q 首调;对照 P1 矩阵。skill 正文首次必算、做差消掉。

### P6 整体收益:轮数 × 业务加权 — 待做

- 左:按会话长度分桶(1Q 51% / … / 6Q+ 11%),列当前/目标推理长度、降幅、占算力、占总节省。
- 右:P3–P5 会话加权 × 业务占比 → 混合整体(每会话 / 每调用)。
- 三句:钱在长对话(6Q+ 一半算力、近六成节省);TTFT ∝ miss,目标与轮数脱钩;1Q 也有固定项普惠(动态精简 + Tools 不再连带)。
- v1 混合 −69%(64.2K→19.6K)方向沿用、数字待 14。

### P7 自动化统计与分析 ✅ v1

- 采集 7 点位(引擎 2 + 埋点 4 + 预热标签);bounds 按新排布;call 含「会话首调」。
- 分析:d 切白算段 → 三张报表(命中率 / 推理长度 / 分桶加权),对应 P2–P6。
- 对比:会话粒度打 scheme;预热切片与无预热账本分开;灰度 + 质量护栏。
- 报警:loop 白算 > 0;目标白算 > 1K/调用;每 Q 节省偏离通式。
- 文件:[自动化统计与分析.v1.slides.html](./自动化统计与分析.v1.slides.html)
  (旧版 [KV-Cache统计点位与自动化.v1.2](./KV-Cache统计点位与自动化.v1.2.slides.html) 仍配合收益闭环 v7.2)

## 3. 术语表

| 术语 | 含义 |
| --- | --- |
| 产品级 | 全网相同、版本发布才变:Tools(最前)、SP 固定、预置 skill |
| 会话级 | 会话创建时确定、会话内不变:SP 内记忆/已安装应用,UAT 头部历史 10 轮 |
| query 级 | 每个 Q 追加:U = query + 动态增量 |
| loop 级 | 每次工具往返追加:A + T |
| 会话首调 / Q 首调 / loop | 会话第一次调用 / 一个 Q 的第一次调用 / 其后迭代 |
| 命中量 d | cached_tokens,前缀一致深度 |
| 命中率 | d / 输入,健康度 |
| 推理长度 miss | 输入 − d,真实 prefill |
| 白算 | 曾算过、因前缀被改写而重算(可根除) |
| 新增 | 本次首次出现的 token(必算) |
| 双次预热 | 会话创建 prefill + query/ASR prefill,推理时命中这两次 |

03两把尺子 + 三个方案:该命中的都命中,命中率是比例,推理长度才是钱每把尺子都给了实测锚点;P4–P6 每页同时报命中率与 miss

① 该命中 / 命中量
cached_tokens = d
前缀逐 token 一致的深度。目标态:产品级全网命中;会话级首调后命中;query / loop 只命中已写入的历史。实测:当前 d 恒停在 SP·固定末(24.6 / 26.6 / 29.6K)。
② 命中率 = 被 cache 的比例
命中率 = d / 输入
健康度,分母漂、折算不成钱。实测:当前 15 次调用均 67%(首调 53–58%);中间态 Q2 起 85–99%。目标随 Q 上升、当前从 Q2 被压住。
③ 推理长度 = miss
miss = 输入 − d = 白算 + 新增
真实 prefill,账单和 TTFT 跟它走。实测:当前首调后 miss 里白算占 90–99%;中间态正常调用 miss ≈ 新增(1 块粒度内)。
④ 验收
白算 → 0(裕量 1 块)
白算 = miss − 新增,新增 ≈ 本次输入 − 上次输入。loop 白算恒为 0 是报警线——当前问答会话一次 loop 全 miss 33.5K,中间态两次异常 47.5K / 16.6K,都该被抓出来。

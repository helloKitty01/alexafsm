# 16 · 数据基线（优化后）

> 目标态物理序。四列，**从上到下 = 送给模型的顺序**。单位 K token（DS-V4 tokenizer）。
> 长度全部为确定数，**与优化前（17）逐项相同**——两边同内容、只换排布，对比才只反映排布收益。
> 高频 skill **不进 SP**，随 U 动态走；动态两边一致，目标不增加。
> 汇报版 v3 P1 即本表 + 17 的渲染；账目与公式见 [18](./18-三页汇报版账目与公式.md)。

`Tools → SP·固定 → 会话级 → 历史 1–10 轮 → UAT-U 动态 → UAT-U query → UAT-A tool call → UAT-T → UAT-A answer`

| 序号 | 名称 | 解释 | 长度 |
| --- | --- | --- | --- |
| 1 | Tools | 全量 12 个工具预置，排到最前。产品级，版本发布才变，全网命中。 | **5.9K** |
| 2 | SP·固定 | 14 个 `##` 段（角色 / 原则 / 规范 / 安全 / TOOLS.md 等）。产品级静态，跟在 Tools 后面。不塞 skill。 | **28.9K** |
| 3 | 会话级上下文 | SP 尾：user.md + 私域原则 + device + 记忆快照。会话创建时冻结，会话内不变；每会话首调算一次，之后命中。 | **1.5K** |
| 4 | 对话历史 1–10 轮 | UAT 头，上一会话载入的完整 U/A/T，不折叠。会话内只追加；每会话首调算一次，之后命中。 | **7K** |
| 5 | UAT-U 动态 | 当轮 user 消息前半：skills 引用、memory、knowledge、前台应用。随 U 追加，不回写 SP。每 Q 必算。 | **3K** |
| 6 | UAT-U query | 当轮 user 消息后半：用户原话，不含注入。永远在动态后面、靠近生成位置。每 Q 必算。 | **0.1K** |
| 7 | UAT-A（tool call） | 本 loop assistant 发出的工具调用（函数名 + 参数）。必算；与最终 answer 分开计。 | **0.2K** |
| 8 | UAT-T（工具结果） | 本 loop 的 tool 消息。必算。下面三行是类型，当轮调了哪类就算哪类；与优化前同长。 | 按 8.1–8.3 |
| 8.1 | └ webSearch | 检索类大结果。问答场景的必算底线。 | **10K** |
| 8.2 | └ SkillLoad | skill 正文首次 load，以 tool result 进消息流。任务每 Q 一次（偏保守）。 | **5K** |
| 8.3 | └ 正常工具 | OpenApp / exec / PersonalContextSearch 等业务工具返回。 | **2.5K** |
| 9 | UAT-A（最终 answer） | 该 Q 最后一次 assistant 回复（不再调工具）。必算（在下一 Q 首调时进入前缀）。 | **0.25K** |

Q≥2 首调只付：上轮 answer 0.25 + 动态 3 + query 0.1 = **3.35K**（幻灯片显示 3.4K）。会话首调另付会话级 1.5 + 历史 7。loop 只付 tool call + T。

# 03 哪些数字不能加在一起

这一周流传的数字来自三张不同的卷子。卷子之间不能相加，也不能写成「又快又准又便宜，所以全面胜过前沿模型」。

## 卷子一：TypeSafe 自己的工作流评测

发布文的做法：假定代码里的计算图是对的，每个模型走同一张图，看谁更接近「最强外部模型的平均预测」。参照是 GPT-6 Astra 和 Fable 5.1 的平均，不是经过核对的标准答案。

由此得出首页的 193.6 倍速度和 444.6 倍成本。发布文的限定一句写完了：

- 这两个倍数处于实际收益的较高端。正文表格里的一般范围是快 40–200 倍。
- 工作流不是为了好看而故意构造的，也不在训练集里。但它们由模型能力团队的人制作，偏差可能存在。
- 参照偏向 OpenAI 和 Anthropic，因此可能低估 Jev，也低估 DeepSeek。
- 对照的 LLM 走的是他们的 System One 包装：强制输出带概率的结构化决定。他们说这是从 LLM 取决定最准的方式，同时更慢、更贵。不带概率的裸决定会显得没那么贵。
- 速度评测多半从西海岸的笔记本打他们当时的服务。

侧面对话演示还有一层：问题键被选成可读的短名，状态是一段短而密的文字，短输入对 Jev 有利。那次记录里和 GPT-5.6 Terra 的唯一分歧，他们自己也觉得题目含糊。Terra 用默认推理，因为他们觉得它和 Jev 的智力最接近。这是厂商的手感，不是公开榜。

类型错误 0% 是接口保证，不是这套工作流里的准确率。工作流量的是「和 Astra / Fable 的平均有多像」。像，不等于对。

## 卷子二：LangChain 的五条天气轨迹

2026-09-20，Daniel Shea 和 Seán Roche 用 Deep Agents 做了一个天气 agent，把五次运行冻结成 LangSmith 数据集。每个裁判对每条轨迹打两个信号：连续的质量分，以及是否通过的二分。人类评审按同一量尺标过这五条，当作 oracle。每个裁判重复 100 次。二分决定因此是 5 × 100 = 500 次。

他们报告的结果：

- 二分上，Jev 和这位评审的 500 次全部一致。GPT-5.6 Terra 99.8%，Luna 96.4%，Claude Sonnet 4.6 80.0%。
- 质量分的逐案例方差，Jev 的观察均值是 0.0000149。Luna 的方差是它的 433 倍，Terra 913 倍，Sonnet 4.6 是 92 倍。博客摘要里的「92–913 倍」就是这三家的范围。
- 速度和花费：平均 0.44 秒、每次 0.00035 美元。全文 Jev 花费 0.34 美元，Claude Sonnet 4.6 是 28.17 美元。LLM 裁判走 LangSmith Gateway，温度等参数用的是各家默认。Jev 经 `langchain-typesafe==0.0.1a2`，实验元数据里没有服务版本。

作者把边界写在文中：方差低不等于更准，一个裁判可以稳定地错；他们不知道方差低是不是训练目标造成的；五条天气轨迹不能外推到别的 agent；便宜会把错误放大，稳定地错会大规模产出坏反馈。人类复核和裁判对齐仍然要做。

这张卷子支持的结论很窄：在「给同一段已完成的天气 agent 轨迹反复打封闭分数」上，Jev 又稳又便宜，并且和这一位评审的通过 / 不通过一致。它不支持「Jev 比 Terra 或 Sonnet 更聪明」，也不支持把它的 0.44 秒拿去和 TypeSafe 的 70 毫秒或 193 倍直接比。任务、包装、是否生成解释，都不相同。

## 卷子三：官方承认的翻车，以及还没证明的单价

`jev-1.13` 的 jaggedness 页是厂商主动缩小适用范围的文本。计数、日期运算、多跳、对抗文本、问法之间的概率恒等式，都在「不要交给它」的清单里。英语是主要训练语言，准确率目前最好。其他语言包括中日韩「能处理，但没有同样好」。非英语工作负载要在自己的内容上测，并盯紧置信度。手机助手的口语是中文，这句直接约束我们，见下一篇。

定价。发布文写：他们无法证明价格没有被补贴，可持续性要靠更长时间，而且他们预期价格往下走。Models 页同时写需求很大、限额在动、更大的 GPU 合同还在落地。Vercel 免费到 9 月 25 日，是渠道补贴，和 API 标价是两本账。0.042 美元是标价，不是这一周用户在 Gateway 上实际支付的数。

数据。Models 页写：不用客户请求和响应训练；企业有零数据保留，细节在法务页。LangSmith 的集成说明另写：那条接入目前不提供零数据保留，送去打分的提示和输出可能被提供方保留。网关按请求打开的 ZDR，和 LangSmith 这条路径，不是同一开关。

## 读这一周新闻时可以留下的句子

Jev 在封闭判断上把解码和解析拿掉了，厂商峰值和工作流评测显示数量级的速度和成本差，LangChain 在一个很小的轨迹打分实验里看到了极低的方差。13% 是免费窗口里的触达。判断的对错、中文、对抗输入、单价能不能维持，都还要在自己的数据上单独证明。

# 2026-09-23 模型与 Agent 怎么选

核对日 2026-09-23。API 价是标准档、短上下文、每百万 token 的输入 / 输出。缓存、长上下文、Batch、Fast 会改账单。效果用 Artificial Analysis 的公开文章，不把不同日期的指数直接加成一张总榜。

没有一个模型在收费、效果、速度、易用上同时第一。先定用途，再选模型和壳。

## 建议

| 你在做什么 | 用这个 | 原因 |
| --- | --- | --- |
| 自己的 agent，日常工具调用 | **GPT-6 Sol** | $2 / $10。Coding Agent Index 57（Codex，max），智力指数单任务成本约 $1.06，是现在编码 agent 的性价比前沿 |
| 自己的 agent，最难的一轮 | **Claude Opus 5.5**，备选 GPT-6 Astra | Opus 5.5 综合指数 58，知识工作领先，API $4 / $20。Astra 在 Codex 里和 Fable 的编码 agent 指数打平（62），但 API 是 $10 / $50，单任务更贵 |
| 高量、可失败重试的步骤 | **GPT-6 Luna** 或 **DeepSeek V4.1 Flash** | Luna $0.10 / $0.50，编码指数 41。Flash 开源权重，非高峰 $0.15 / $0.60，解码约 220 token/s，智力指数约 40，不是旗舰 |
| 人每天写代码 | **Claude Pro（$20）里的 Claude Code**，用量不够再 Max $100 | 壳和项目记忆最顺。要更省 token 的编码 agent，用 ChatGPT Plus 里的 Codex + Sol |
| 人要在对话里用最强模型 | **ChatGPT Pro $100** 才有聊天里的 GPT-6 Astra；Claude Max $100 才比较用得动 Fable | Plus 的 Astra 只在 Work 和 Codex，不在普通聊天 |
| 普通人的生活代办 | 先不要交给 Muse 外呼 | 零配置和 WhatsApp 是真的，美国限定。9 月 22 日 Reuters：未披露的人工代打电话已回滚。任务可靠性还没过关 |
| 手机助手 / OpenClaw 这条线 | 模型用 Sol，许可不要交给模型 | 贵模型补不了「批准在循环外、凭证不进上下文」。OpenClaw 负责壳，Sol 负责大多数回合，难回合再升 Opus 5.5 |

一个人日常保留一个 $20 档就够。同时订 Claude、ChatGPT、Grok、Gemini 的 $100 档，多出来的是重复的聊天窗口，不是更可靠的 agent。

## 速度

旗舰的等待几乎都花在思考，不花在解码。

| 观察 | 数字 | 怎么用 |
| --- | --- | --- |
| Anthropic 自己的延迟档 | Fable 更慢，Opus 5.5 中等，Sonnet 快，Haiku 最快 | 交互式前台用 Sonnet 或 Sol，不要用 Fable / Astra max |
| Grok 4.7 | 长提示约 188 token/s，智力指数每任务约 7.1 分钟，输出约 81K token | 比 Grok 4.6 更强，也更费 token。Astra max 同期约 27K 输出 token/任务 |
| Grok 4.6 xhigh | 首 token 约 40 秒，解码约 55 token/s | 高思考档的首字延迟，不是解码慢这一件事 |
| DeepSeek V4.1 Flash | 约 214–220 token/s，首 token 约 1.1 秒 | 便宜档里最快的一档。智力指数 40 |

OpenAI 的 Fast 模式把延迟买回来，价格 ×2。能用 Sol 的默认档完成的步骤，不要为了 Astra 的 max 去等。

## 不要这样选

- 用综合指数第一名包下所有回合。Opus 5.5 的 $20 输出价，跑 Luna 能做的分类和改写，是在为思考付钱。
- 用九题排名选底座模型。那次 Muse 垫底，是产品校准和人工边界的问题，不是 Spark 不能用。
- 把 contributor 档的 Muse Spark 放进带用户隐私的手机助手。那一档的条件是数据用于改进 Meta 产品。
- 为了「更快」把推理档开到 max。max 增加的是思考 token 和时间，解码速度几乎不变。

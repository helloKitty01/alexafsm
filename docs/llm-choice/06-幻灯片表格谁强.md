# 幻灯片、表格、HTML 谁强

核对日 2026-09-23。没有一份公开榜把 PPT、表格、HTML 拆开打分。能用的是 Artificial Analysis 的 GDPval：44 个职业的真实任务，交付物包括文档、幻灯片、图和表格，盲比 Elo，人类基线锚在 1000。HTML 汇报页靠近其中的幻灯片，不靠近终端题，也不是一份单独的网页榜。

两套版本不要加成一张表。

## v2：Fable 5.1 仍排第一

[GDPval-AA v2 排行榜](https://artificialanalysis.ai/evaluations/gdpval-aa) 当天抓到的前排（max 或该模型的最高档）：

| 名次 | 模型 | Elo |
| --- | --- | --- |
| 1 | Claude Fable 5.1 max | 1764 |
| 3 | Claude Opus 5 max | 1735 |
| 5 | Muse Spark 1.3 max | 1703 |
| 6 | Qwen3.8 Max（0902） | 1689 |
| 7 | Grok 4.6 xhigh | 1663 |
| 9 | GLM-5.3 max，以及 GLM-5.3-Flash | 1655 |
| 15 | DeepSeek V4.1 Flash max | 1632 |
| 20 | GPT-5.6 Sol max | 1624 |
| 22 | GPT-6 Astra max | 1580 |
| 33 | Claude Sonnet 5 max | 1501 |
| 40 | Gemini 3.8 Flash high | 1464 |

Fable 5.1 的 high 是 1650，medium 是 1579。不把 effort 开高，它就不在这一档的最前。Opus 5 max 和 Fable max 的置信区间几乎贴在一起。Muse Spark 1.3 max 是非 Anthropic 里最靠近的一个。Sol max 高于 Astra max，仍低于 Fable 那一簇。Flash、Sonnet 5、Gemini 3.8 Flash 不在这一簇。

## v2.1：Opus 5.5 超过 Fable

Anthropic 在 [Opus 5.5 发布页](https://www.anthropic.com/claude-opus-5-5) 引用的是更新后的 GDPval-AA v2.1，Artificial Analysis 的对照页也给出同一套分。这套分把 Fable 从 v2 的 1764 改写成 1735，所以不能拿 v2 的 Muse 1703 去和 v2.1 的 1846 比。

| 模型 | GDPval-AA v2.1 |
| --- | --- |
| Claude Opus 5.5 max | 1846 |
| Claude Fable 5.1 | 1735 |
| Claude Opus 5 | 1708 |
| GPT-5.6 Sol | 1588 |
| GPT-6 Astra | 1542 |

Opus 5.5 的 API 是输入 $4、输出 $20、缓存读 $0.20，大约是 Fable 的四折到半价。Anthropic 写明：自己用下来，它和 Fable 的差距比这些分数看起来更窄。默认 effort 是 medium；他们称 medium 在这套知识工作上超过 Astra 的 max，单任务成本大约是五分之一。同一页的内部测试里，它先做 Excel 财务模型，再做成高管汇报，比 Opus 5 更完整，时间 63 分钟对 93 分钟。一家早期测试方提到，它的幻灯片更密，更接近行业里常见的密度。

## 怎么用在汇报页上

幻灯片和表格先试 **Opus 5.5**。它和 Fable 在同一个 Claude 壳里，v2.1 上这一类交付物更高，token 更便宜。选择器里还没有 5.5 时，用 **Opus 5 max**，它在 v2 上紧挨着 Fable。

要换一家：按 v2 的顺序是 **Muse Spark 1.3 max**，然后 Qwen3.8 Max、Grok 4.6、GLM-5.3。这些是「强于 Astra」，不是已经证明和 Fable 的 HTML 汇报页同一档。Spark 用标准 API 档（$1.25 / $4.25），不要用会把数据拿去改进产品的 contributor 档。

OpenAI 里这一类相对最好的是 **GPT-5.6 Sol max**，不是 Astra。它仍低于 Fable / Opus 那一簇。DeepSeek V4.1 Flash 在 v2 上高于 Astra，低于 Fable 大约 130 分 Elo，不拿来换汇报页。

HTML 汇报页还有一层 GDPval 没单测的约束：固定 16:9、不许溢出、要跟已有样式。换模型之后用同一套版式检查看，不要只看榜上的 Elo。

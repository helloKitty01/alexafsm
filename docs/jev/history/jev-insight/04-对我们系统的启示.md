# 04 对我们系统的启示

对照的是 [phone-assistant-automation/](../../../phone-assistant-automation/)（全双工前台、非 LLM 中枢、深度模型后台、打扰管理器）和 [openclaw-automation/](../../../openclaw-automation/) v4（创建期从五个模板里选一个，不可逆动作是模板，批准卡 / standing grant）。Jev 给这两份设计补的是一个快裁判，不改它们已经定下的放行权。

## 它正好长在我们已经分开的那条缝上

中枢是常驻的，不靠模型活着。深度模型负责要写、要多步工具的活。中间有一大类判断既不该手写成死规则，也不该每次叫醒 Fable 或 Sol：这则通知急不急、这轮要不要插话、五个模板里哪一个像、这段轨迹算不算做完、检索回来的段落和问题有没有关系。

这些都是封闭问题，选项我们可以事先写出来。Jev 的 Choice / Score / Noul 就是这个形状。70–500 毫秒的官方延迟区间，落在「请求路径上可以等」和「全双工里不能等它写一段解释」之间。输出免费，则让「每个事件都问一次」在账单上变得可讨论。可讨论不等于应当每帧都问。他们自己的 Doom 演示是每秒 10 次、大约 7 美元一小时。前台音频如果按帧去打分，Jevons 那种「更便宜所以调用暴涨」会先发生在我们自己的打扰链路上。

## 可以交给它的三处

**打扰分级的输入，不是出口。** 打扰管理器仍是唯一出口，级别仍是 speak_now / speak_at_pause / push / digest / hold。Jev 可以给一条事件打紧急程度和「值不值得浮出」的概率。代码用阈值映射到级别。阈值按我们的风险分界校准：只读、公开、可逆用一档；对外、花钱、难撤销不走这个映射，直接 `waiting_user`。官方文档已经要求破坏性动作用更高的置信度，我们比这更硬：钱、发送、删除即使 confidence 很高也不自动做。高置信度是「可以少打扰用户去确认一件可逆的小事」，不是放行令。

**创建期的模板选择。** v4 规定模型只从五个固定模式里选一个并填参数。选模式是 Choice，填时间、对象 ID、阈值里那些封闭字段也可以是 Choice 或 Noul。置信度不够就问用户，而不是让模型自由发明第六个模式。参数里的自由文本（提醒文案）仍交给会写字的模型，或用用户原话。Jev 串 Choice 来造句子，官方写明又慢又差。

**轨迹和工具结果的验收。** 「检索是否相关」「最终回答是否落在给出的证据里」「这一步算不算做完」适合 Noul 或 Score，和 LangChain 那张小卷子是同一形状。用法是回归和在线抽检，先在我们自己的标注上看置信度和准确率是否一起走。一个稳定但错的裁判会把坏信号放大，LangChain 把这句写进了结论。验收失败的处理仍是现有的重试、问用户或停止，不由 Jev 临时改 Policy。

## 留在代码和慢模型里的部分

- 计数、日期先后、金额运算。官方建议抽取用封闭选项，比较和加减在代码里。手机上的「三点之后提醒我」尤其如此：抽出「小时 = 15」可以问它，和现在时间比大小不要问它。
- 多跳和字面否定。问题要写成直接的那一句。同一政策不要同时用 Noul 和 Choice 各问一遍再假设两者互补。他们自己的例子里两者加起来不是 1。
- 中文口语。文档写明中日韩没有英语那么好。接进前台之前，用我们的通知、口语、模板描述做一套标注，单独看校准。英语演示上的 0.8 阈值不能搬过来。
- 对抗文本。状态里的网页、邮件、README、对方发来的消息都能推动答案。昨日简报里的休眠条件（arXiv:2609.22510）不会因为裁判换成 Jev 就自动失效。读过不可信内容之后，自动放行仍然取消。Jev 的判断结果也是不可信输入的函数，中枢只把它当建议分。
- 工具排序的安全证明。昨日的反事实工具排序（arXiv:2609.22819）已经说明：历史回报上的「这个更好」不是部署许可，模型还可能不肯弃权。Jev 的概率同样不是许可。弃权由我们的阈值和 `waiting_user` 实现，不指望模型自己说「都不该做」。
- 生成。回复、幻灯片、HTML、工具参数里的开放字符串，继续用 [llm-choice](../../../llm-choice/) 里已选定的慢模型。Jev 不进入那张质量对照。

## 中枢仍然不是模型

把 Jev 放进中枢进程，中枢就又依赖一次外部推理：限额在动（官方写 1200 请求/分钟、25 万 Token/秒，且会变）、版本别名会悄悄换、企业 ZDR 和 LangSmith 那条路径的保留策略也不一样。触发器、任务存储、批准卡的语义保持在不调用模型也能跑的代码里。Jev 超时或 429 时，分级落回预先写好的保守档（hold 或 digest），而不是卡住前台，也不是改走慢模型把每条通知都讲一遍。

慢模型继续做它擅长的长输出。Jev 只减少那些本来不该产生长输出的调用。两本账分开记：一次 Jev 判断的成本和一次 Fable / Sol 写作的成本不要合成「agent 便宜了多少」。合成之后，Jevons 效应会被算成节省。

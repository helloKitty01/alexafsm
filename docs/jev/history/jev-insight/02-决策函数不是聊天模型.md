# 02 决策函数不是聊天模型

Jev 是一个函数：同一份状态，一组事先声明的问题，并行得到答案和概率。代码负责把这些数合成分支。模型不负责把分支写成一段话。

## 一次调用里有什么

文档里的三种问题：

| 类型 | 问的是 | 返回 |
| --- | --- | --- |
| Choice | 哪一个选项 | 选中的键、各选项概率、由分布算出的 confidence |
| Score | 落在有序量尺的哪一档 | 分数、各档概率、confidence |
| Noul | 一个是非判断为真的概率 | 0 到 1 的数。Noul 不带 confidence |

同一请求里的问题互相看不见。文档写明：一个问题的结果不会变成另一个问题的隐藏上下文。状态可以是短文，也可以是 JSON。官方建议只放这个问题用得着的字段，无关内容会拉低准确率，他们称之为 context rot。

Choice 的基数上限在发布文里是 255。再大就走两段：先独立打分，再做一次显式选择，所以偶尔变慢。生成文本不在训练目标里。官方的替代做法是：用正则或其他模型抽出候选，让 Jev 在候选上做 Choice。把 Choice 串成句子，文档写明又慢又差。

`jev-latest` 在所读文档里指向 `jev-1.13.0`。别名会在发新版时自己挪。调过阈值的调用应钉死版本号，响应里的 `model` 字段会写明实际回答的版本。权重不分客户微调，也不做 LoRA。领域差别写在 `state`、`instructions` 和 `criteria` 里，由代码把原子问题拼起来。

## 并行采样改变的是哪一种成本

聊天模型先把答案写成 Token 序列，程序再解析、再校验。序列越长，等待越长，输出账单越贵，解析还有一次失败的机会。Jev 在问题声明的那一组值上直接出分布。发布文的原话是：放弃字符串，换来的是速度。

这也是输出免费在商业上说得通的原因。官方没有公开算子级的成本拆分，只公开了结果侧：输出免费，并写明他们还不能证明这个价格没有补贴，长期看他们预期价格下降。补贴与否先搁在第三篇。机制上已经能确定的是：调用方不用再为「解释为什么选 A」付解码费，除非自己另叫一个会写字的模型去写解释。

置信度是分布形状的一个统计量，不是第二个模型。Choice 和 Score 上，分布越平，confidence 越低。文档给的用法是三段：高则自动做，中则加确认或再取信息，低则不要做，转人、转澄清，或转一个更贵的推理模型。阈值按动作的后果分开。只读和会删数据不是同一个数。

## 「不能幻觉」保证的是类型

发布文写了 “can’t hallucinate”，同一段又写：可能的输出和结构事先定义，模型不会产生类型错误。证据小节把话说死了：类型安全那个 0% 不是测出来的，schema 匹配在接口上成立，所以他们直接把 0 画进图里。一个反例就能推翻；他们认为这在数学上不会发生。

判断对不对是另一件事。官方 jaggedness 页（`jev-1.13`，最后审阅 2026-09-17）列出的失败都是「类型正确、内容错」：

- 它回答写下来的那句，不回答你心里的那句。否定和隐含条件按字面读。
- 计数不可靠，误差随长度涨。算术留在代码里。
- 日期是文本，不是有序的量。抽取可以交给它（月份、日都是封闭集合），先后和间隔留在代码里。
- 多跳、双重否定、无关的长状态，准确率下降。
- 状态默认不被当成敌对输入。注入进来的指令、故意带偏的框架、替自己的分类辩护的文字，都能推动答案。
- 同一问题的两种问法不必满足概率恒等式。他们自己的例子：一张工单上「在要求退款」的 Noul 是 0.72，「在要求退款以外的事」是 0.47，加起来 1.19。另一张上 Noul 0.22，同时 Choice 的 yes 只有 0.01。阈值不能从一种问法搬到另一种问法。

所以自动化里真正被拿掉的，是「返回了一个不在 schema 里的工具名 / 一个解析失败的 JSON」。昨日雷达里的工具幻觉（伪造工具名）这一类，封闭问题的接口能挡在外面。昨日雷达里的休眠条件注入，官方已经写明对抗文本能推动答案，不能假设 Jev 天然是那道摄入时检测器。

RLCD（Reinforcement Learning for Calibrated Decisions）是他们给训练方法起的名字。发布文的目标函数是：系统一任务上，概率在认识上诚实，高置信对应高准确，相似输入给出相似答案。算法步骤、数据来源、奖励的具体形式，发布文留在 FAQ 里，没有展开到可以复述的程度。这里不补。能用的工程含义只是文档里那句：置信度用来决定自动做、复核，还是升级，而且要在你自己的标注上校准。

## 它和聊天模型怎么拼

发布文把用途收成几类：工作流里的智能 if、大数据上的 map-reduce、100 毫秒级的实时分支、以及给别的模型的提示、轨迹和输出打分。人面对的写作、要迭代验证的数学和内核优化、偶尔才对的原型，仍放在会生成字符串的模型上。

一次生产路径因此是两段。Jev 在封闭问题上分支，并把不确定的部分标出来。会写字的模型只在确实要产出文本、或置信度不够需要展开推理时被叫到。叫它的次数由代码的阈值决定，不由 Jev 自己决定再叫一次。

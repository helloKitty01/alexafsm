# 01 需求与场景：手动进入、自动截「换页」、不存重复图

> 目标：把「开会看对方 PPT / 上网课」时的自动截图需求写成可验收的场景，
> 作为 02 管线与 03 平台方案的输入。不在本章选算法。

## 1. 一句话问题

用户在**自己决定的一段时间里**打开自动截图，系统持续看着屏幕，
每当对方翻到一页**新的、已经停稳的**内容就留一张清晰图；
过渡动画、摄像头小窗、鼠标、回翻到已经截过的页，都不要再存一份。

关键词是**用户触发的会话**，不是常驻监视：没开模式就不采屏。

## 2. 用户怎么用（交互骨架）

1. **进入**：用户点浮动钮 / 通知栏开关 / 快捷键 / 语音「开始自动截图」。
   系统先走平台要求的录屏/截屏授权（每次会话或按系统策略缓存）。
2. **确认范围**（能选就选，选不了就整屏）：
   - PC：指定窗口（会议窗口、浏览器、PPT 放映窗）或框选区域；
   - Android 14+：尽量用「仅此应用」投影，避免把通知栏和桌面也采进去；
   - iOS：只能录屏，范围由系统决定。
3. **进行中**：状态栏 / 岛 / 浮动条明确显示「自动截图中 · 已保存 N 张」，
   必须能一键停。锁屏、用户切走、系统收回权限 → 停或暂停，不得偷偷继续。
4. **退出**：再点一次或超时。给出本场缩略图条，允许删一张、补截当前屏、导出。
5. **结果**：本场一个文件夹 / 相册专辑。默认不上传云。

进行中**不要弹「又截到一张」的全屏打扰**。角标数字足够；出错（权限被收、空间不足）才出通知。

## 3. 「重复」的产品定义

用户说「重复的图不要」，实际混了四类不同失败。验收时必须分开计：

| 代号 | 用户观感 | 正确行为 | 反例 |
| --- | --- | --- | --- |
| Dup-A 过渡 | 淡入淡出、擦除、翻页动画截到一半 | 不存中间帧 | 一张半透明叠两页 |
| Dup-B 动画构建 | 同一页逐条出现 bullet / 图表往上长 | **默认只留停稳后的最终态** | 一页变成 6 张只差一行 |
| Dup-C 相邻几乎一样 | 鼠标动、光标闪、时间秒数、头像在说话 | 不存 | 一秒一张「几乎一样」 |
| Dup-D 回翻 | 讲师回到目录或上一页 | 本场已有近似图则跳过 | 目录被截了五次 |

默认策略：**Dup-B 取最终态**。需要「逐步板书每一帧」的人用高级开关「捕获每一次明显变化」。
这两档不能混成一个灵敏度滑条——灵敏度管的是 Dup-C 的阈值，管不了「要不要动画步骤」。

## 4. 场景矩阵

| # | 场景 | 画面特点 | 成功标准 |
| --- | --- | --- | --- |
| S1 | 腾讯会议 / Zoom / Teams 对方共享 PPT | 幻灯片 + 头像小窗 + 会议控件 | 只跟幻灯片走；头像说话不触发 |
| S2 | 网课（课堂 App / 浏览器）老师翻页 | 主画面是课件，可能有弹幕、进度条 | 翻页存一张；弹幕飞过不存 |
| S3 | 本地全屏 PPT / 投屏 | 几乎整屏都是幻灯片 | 换页存；激光笔 / 鼠标不存 |
| S4 | 网页课件、PDF 滚动 | 不是整页切，是滚动或分栏 | 明显翻到下一屏才存；细微滚动不刷屏 |
| S5 | 回翻目录 / 上一页 | 内容回到本场已见过 | 不新增；可在已有缩略图上标「再次出现」 |
| S6 | 逐条出现的动画页 | 同一页停留很久，局部一点点变 | 默认 1 张最终态；开「逐步」才多张 |
| S7 | 老师切到摄像头特写 / 休息画面 | 没有幻灯片结构 | 尽量不存；或标成「非课件」进回收而不是正集 |
| S8 | 用户自己划一下、回消息、出通知 | 本机 UI 叠在课件上 | 不把通知/输入法当成新页；PC 指定窗口可自然避开 |
| S9 | 锁屏、来电、录屏权限被系统收回 | 采集中断 | 停会话并告诉用户已保存 N 张，不丢已落盘 |
| S10 | 用户中途手动补一张 / 删一张 | 人是最终裁判 | 手动补的强制入正集；删除后回翻不再自动加回 |

不做进一期矩阵、但要心里有数的：带手写板书的物理黑板（连续变化，没有「页」）、
电影/视频课（期望按镜头而不是按页）、游戏。这些不是本功能的主路径。

## 5. 非目标（一期明确不做）

- **不常驻后台盯屏**。没有用户手势就不申请录屏权限、不采帧。
- **不把帧送到云或大模型做热路径判定**。隐私（会议）和功耗都过不了。
- **不保证截到「共享内容」的原始视频流**。第三方会议 App 很少把共享流单独开放；
  我们截的是用户看见的那块屏幕/窗口。
- **不做实时 OCR 字幕、不自动生成讲义摘要**。那是会后处理。
- **不在 iOS 上承诺静默截图**。系统不允许。
- **不替代用户对敏感信息的判断**。模式开着就会把当时屏幕上的东西留下；
  需要在进入时用一句话讲清楚。

## 6. 非功能约束

| 项 | 要求 |
| --- | --- |
| 隐私 | 帧不出端；分析分辨率可以很低，原图只在「决定保存」时编码落盘 |
| 功耗 | 分析 1–4 fps 即可；长时间无变化再降采样。手机必须前台服务 + 可见指示 |
| 存储 | 一场课按 50–150 张 JPEG 计，不要无上限；达上限停并提示 |
| 时延 | 翻页后 0.5–2 s 内落盘可接受，不需要「当前帧立刻出图」 |
| 可关 | 任何时刻一次手势停掉采集；系统锁屏默认停 |
| 可解释 | 每张保存图能回答「因为和本场已有图的 pHash 距离 ≥ T」，方便调参 |

## 7. 验收口径（最小）

拿一段 20 分钟、约 30 页、含头像小窗和 3 次回翻的会议录像当输入（PC 可直接播；
手机用投屏或本机播放）：

1. 正集张数在 28–40 之间（允许漏 1–2 页快闪，不允许 80+ 张近重复）；
2. 回翻目录不新增文件；
3. 头像说话、鼠标移动不单独成张；
4. 淡入中间帧不进正集；
5. 用户中途点停，已保存文件仍在。

阈值允许按「宽松 / 标准 / 严格」三档预置，但默认档必须过上述口径。

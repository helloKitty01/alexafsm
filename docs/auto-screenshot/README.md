# 会议 / 网课自动截图（去重）

用户手动进入「自动截图模式」，在会议共享 PPT、网课翻页等场景里持续采屏，
只保留**内容真正换页**后的清晰图，丢掉动画中间帧、摄像头小窗抖动、回翻已见过的页。

这不是 Agent loop 问题，也不是「每隔 N 秒盲截一张再靠模型挑」。
推荐做成**端上、无云、可关**的四段管线：采屏 → 变化检测 → 稳定门 → 会话级去重。

## 核心结论（当前版本）

1. **热路径必须是本地、廉价、可解释的视觉算法**，不要把每一帧送给大模型。会议内容敏感、手机功耗敏感、翻页判定也不需要语义理解。
2. **「不要重复图」要拆成三件事**：过渡/动画未停稳不存、与上一张几乎一样不存、本场已经存过的页（回翻）不存。只做相邻帧差分会漏掉回翻。
3. **会议场景的主干扰不是压缩噪声，是持续运动的区域**（头像、鼠标、秒表、弹幕）。变化检测必须带 ROI / 忽略区，否则会把「老师动了一下」当成翻页。
4. **PC 比手机容易、Android 比 iOS 容易**。PC 可指定窗口并拿脏矩形；Android 用 `MediaProjection`；iOS 只能走 ReplayKit 录屏扩展，系统必出录制指示器，做不到静默截屏。
5. **一期只做「手动开/关 + 本场去重落盘」**。OCR 题名、导出 PDF、模型挑「这是不是幻灯片」都放到会后或二期，不挡最小可用。

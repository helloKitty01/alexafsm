# 图片搜索 × 创建相册（含 500 条分页与增量更新）

两个 skill 的组合场景：创建相册 skill 依赖图片搜索 skill（单向）；搜索工具每次最多返回 500 张；
「帮我把小猫的图片创建相册」一周后再说一次时只加新增的图，需要搜索工具支持可选的 `exclude_album` 排除字段。
本目录沉淀需求与场景描述、当前 / 目标方案对照、三项拍板、方案依赖与挑战。

**v2.1 要点**：先给「当前方案」（模型驱动翻页与排除）再给「目标方案」，同一张分层架构图只标四处变化——搜索工具 `exclude_album`、复合工具 `add_from_search`、相册服务 `removed`、引擎排除下推；五个优化点（默认增量 / 排除含移出记录 / 工具吞掉翻页 / 排除与游标的分工 / 报数在前）。
相对 v2 的修正：**exclude 定义「增量集合」，游标负责「运行内定位」，引擎能读己之写时两者合一**——纯「排除即翻页」依赖 add 后 search 立刻看到新成员，相册索引异步更新（T_sync 几十秒）时会静默少加；四页专题讲问题时序 → 根因（排除集烘进索引 vs 查询时反连接）→ 工具内三种策略与决策表（推荐 exclude 播种 + 游标定位）→ 对报数 / 连续调用 / removed 的影响与延迟注入验收。

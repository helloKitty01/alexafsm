# 图片搜索 × 创建相册（含 500 条分页与增量更新）

两个 skill 的组合场景：创建相册 skill 依赖图片搜索 skill（单向）；搜索工具每次最多返回 500 张，超出需翻页；
「帮我把小猫的图片创建相册」一周后再说一次时只加新增的图，需要搜索工具支持可选的 `exclude_album` 排除字段。
本目录沉淀需求与场景描述、方案依赖与挑战、待拍板项。

# 图片搜索 × 创建相册（含 500 条分页与增量更新）

两个 skill 的组合场景：创建相册 skill 依赖图片搜索 skill（单向）；搜索工具每次最多返回 500 张；
「帮我把小猫的图片创建相册」一周后再说一次时只加新增的图，需要搜索工具支持可选的 `exclude_album` 排除字段。
本目录沉淀需求与场景描述、三项拍板、方案依赖与挑战。

**v2 要点**：① 同名相册默认增量、多本才问；② `exclude_album` 语义 = members ∪ removed，移出记录由相册服务维护；
③ 相册流程里模型不翻页——「排除即翻页」（exclude 指向正在加的相册，每次搜到的就是下一批不在册的 500 张）替代游标，
复合工具 `add_from_search` 在工具内部吞掉循环，首次与增量同一条链路、3 个 loop 且与张数无关；cursor 只保留给纯搜索。

AGENT VARIABLE SCHEME · V4

Agent 变量方案
Working Memory + 信封 + ${resultId.key} 引用替换

一句话：A 工具结果由框架存进 Working Memory 并包一层信封给模型， 模型调 B 工具时用 ${resultId.key} 引用，框架在执行 B 之前替换成真实值。

解决什么

长内容（URL / 路径）复述导致的输出时延与抄写错误：80+ tokens → 8 tokens，抄错归零

工具零改动

A 原样返回、B 收到真实值，两端对变量机制零感知

模型零拼装

直接 id + 字段名引用：${a3f8k2p9.img_uri}

01完整流程：A 执行 → 结果处理 → 模型 → B 替换执行

① 执行 A 工具image_gen 原样返回
{"img_uri": "…246字符…", "createTime": "…"}
→
② 框架处理结果生成 resultId=a3f8k2p9
原始结果原样存 Working Memory
→
③ 信封给模型长值瘦身 $preview
短值原样可推理
→
④ 模型输出 B 调用参数写 ${a3f8k2p9.img_uri}
（skill 中有指引）
→
⑤ 框架替换变量查 Working Memory
→ 完整真实值
→
⑥ 执行 B 工具收到真实值执行
B 的结果回到 ②

替换时机：schema 校验之后、执行之前的最后一步；替换后的真实值不回写对话历史，历史里永远是 ${…}。

循环闭环：B 的结果同样走 ②③，每个工具结果都有自己的 resultId，多轮对话中随时可引用。

02信封：内存存什么 vs 模型看到什么

Working Memory 存的（KV，原样）

a3f8k2p9 → {
  "img_uri": "https://cdn.example.com/imgs/2026/08/10/
      f7c3a91e-…-4096.png?sig=Kx7Qw9f2…&exp=1754800000",
  "createTime": "2026-08-10T04:05:12Z"
}

工具原始返回，一字不改。生命周期：默认当前 loop，被引用即提升为会话级并续期。

模型看到的信封

{
  "toolName": "image_gen",
  "responseText": "已生成图片。引用时请使用
      ${a3f8k2p9.字段名}，不要抄写内容。",
  "resultId": "a3f8k2p9",
  "resultData": {
    "img_uri": { "$preview": "https://cdn.example.com/…?sig=Kx7Q…",
                 "$size": 246 },  // 超阈值 → 瘦身
    "createTime": "2026-08-10T04:05:12Z"  // 短值原样
  }
}
resultData = 原始结果的 key/valueresultIdresponseText
结构不变；超阈值（默认 200 字符）的 value 瘦身为 {$preview, $size}，短值原样保留供模型推理 框架生成的 8 位随机 id，跨轮唯一 工具提供，缺省框架生成；附一句引用提醒

03引用与替换：${resultId.key}，两种落点

invoke() —— 值语义注入

invoke("edit_image", {
  "source": "${a3f8k2p9.img_uri}",
  "op": "crop", "ratio": "16:9"
})

保留类型；字符串内可拼接 ${id.key}/sub/path；嵌套结果按路径写 ${id.items[0].url}

exec(command) —— 自动 shell 转义

exec(command="curl -o /tmp/img.png ${a3f8k2p9.img_uri}")

// 框架替换 + 转义后实际执行：
curl -o /tmp/img.png 'https://cdn.example.com/…&exp=…'

单引号包裹：URL 中 & 不会截断命令，注入载荷无法逃逸。转义由框架做，模型和 skill 不管。

Skill 指引（写进工具描述）

"参数值来自上游工具结果时，直接写 ${resultId.字段名} 占位符，不要复制其内容，框架会自动替换。"

出错即回喂

id 不存在 / 字段不存在 / 已过期 → 不执行工具，tool error 附该 resultId 可用字段清单，模型自纠重试

04生命周期与落地

创建信封生成时入库
默认 loop 作用域
→被引用
提升 + 续期conversation 作用域
跨轮可引用
→N 轮未引用
降级 / 淘汰大值先降级磁盘（可读回）
TTL 到期淘汰
→物理失效
过期签名 URL 等有效期
引用报错 + 提示重取
模块职责
Enveloper生成 resultId、原始结果入库、长值瘦身、包信封
WorkingMemoryKV 存取、作用域/TTL、随对话 checkpoint（恢复后 ${…} 不悬垂）
Resolver${} 解析、按落点替换与转义、错误回喂
Skill 规范依赖上游结果的参数附一句引用指引

安全约定

  • 只替换参数值 / 命令字符串位置
  • 工具结果原文中的 ${ 入库转义，防伪造引用
  • exec 落点强制框架转义

# 02 上下文分层与排布

## 原则：按"变化频率"排序，而不是按"逻辑重要性"排序

上下文从前到后，变化频率必须单调递增。稳定的在前，易变的在后。
这是 KV cache 友好排布的唯一硬原则。

```text
┌─────────────────────────────────────────────┐
│ L0 产品级稳定（整个产品所有会话相同）          │  ← 永不变化
│    - system prompt 主体                      │
│    - 核心工具全集的 schema 定义               │
├─────────────────────────────────────────────┤
│ L1 会话级稳定（会话开始时确定，会话内冻结）     │  ← 每个会话变一次
│    - 用户画像 / UAT 类信息                    │
│    - 长期记忆（会话开始时检索一次）            │
│    - 会话级环境信息（工作目录、日期等粗粒度）   │
├─────────────────────────────────────────────┤
│ L2 query 级（随每个用户 query 变化）          │  ← 每个 query 变一次
│    - 本轮检索的知识 / 记忆增量                │
│    - 本轮相关的 skill 文档                   │
│    - query 级环境上下文                      │
│    → 全部放进【当轮 user message】里          │
├─────────────────────────────────────────────┤
│ L3 loop 级（每次工具调用追加）                │  ← 只追加，不修改
│    - assistant tool calls / tool results     │
└─────────────────────────────────────────────┘
```

## 关键决策点

### 1. 检索内容注入位置：放进当轮 user message，不放 system prompt

- 放 system prompt 头部 = 每个 query 全量 miss（最坏方案）。
- 放最新 user message（如包一层 `<retrieved_context>` 标签）= 之前的全部
  历史照常命中，只有新增部分需要 prefill（最优方案）。
- 多轮会话中，**不要原位刷新**旧的检索块。新 query 的检索结果作为新消息的
  一部分追加。代价是同一条知识可能重复注入，用增量去重解决：维护本会话
  已注入条目的 ID 集合，只注入新条目。

### 2. 动态工具检索：不要动 tools 参数，保持 schema 区稳定

工具 schema 序列化在上下文最前部。每个 query 换一批工具 = 每个 query 全量 miss。
候选方案按推荐度排序：

- **方案 A（推荐）**：核心工具固定为小而全的超集（读/写/执行/搜索等原子能力），
  永不增删；动态检索出的 **skill 以文本形式**注入 L2（skill 本质是提示词文档 +
  对原子工具的使用方法，不需要独立 schema）。
- **方案 B**：两级工具。schema 区只有稳定的 meta-tool（如 `load_skill(name)`、
  `dispatch(capability, args)`），具体能力在运行期通过 meta-tool 加载，
  加载结果作为 tool result 追加（L3，天然缓存友好）。
- **方案 C**：如果自建推理（vLLM/SGLang），保留全量工具 schema，
  用 logits masking 屏蔽本轮不可用的工具，schema 区完全不动。
- 反模式：按 query 检索 top-k 工具直接塞进 tools 参数。

### 3. UAT / 用户信息：升到 L1

用户级信息在一个会话内几乎不变，没有理由按 query 重算。会话开始时取一次快照，
放在 L1 冻结。会话中途确需更新时，以"增量消息"的形式追加到 L3，而不是回头改 L1。

### 4. 缓存断点（Anthropic 风格显式 cache_control）

四个断点的典型分配：L0 工具区末尾、L0 system 末尾、L1 末尾、L3 对话尾部滚动。
OpenAI / vLLM 自动前缀缓存则只需保证上述排布即可。

## 一个对照示例

反模式（每 query 全量 miss）：

```text
system: 你是助手…
        [当前时间: 2026-08-24 00:58:31]        ← 秒级时间戳，天然毒药
        [用户画像: …每轮重新生成…]
        [本轮检索知识: …]                       ← 检索内容在前缀
tools:  [根据 query 检索出的 8 个工具]           ← 工具区每轮变
messages: …
```

推荐模式：

```text
system: 你是助手…（静态，含日期到"天"级）
tools:  [固定核心工具超集]
messages:
  user#1: <user_profile>…会话开始时注入一次…</user_profile>
          <retrieved_context id=r1>…</retrieved_context>
          <query>用户问题 1</query>
  …（历史照常追加，全部命中）…
  user#N: <retrieved_context id=rN>…仅增量条目…</retrieved_context>
          <query>用户问题 N</query>
```

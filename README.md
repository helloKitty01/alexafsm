# AI 文档库

## 协作约定

详见 [AGENTS.md](./AGENTS.md)，要点：

- **所有修改直接在 master 分支上提交并推送**，禁止新建任何分支、不开 PR；
- 所有文档统一放在 `docs/<主题>/` 下；
- 每个目录只保留同一系列的最新版本，历史版本归档到同目录的 `history/` 子文件夹。
